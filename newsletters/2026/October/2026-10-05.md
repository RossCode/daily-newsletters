## Top Stories

### [Meta's Muse agent is everywhere, and so are the worries](https://www.mbi-deepdives.com/no-ads-muse/)
*(5 newsletters)*

Meta's Muse agent showed up across the weekend's coverage from every angle. One analysis argues Muse may never need ads because merchants pay transaction fees instead, while another warns that an agent handling shopping, bookings, and travel could build deeper habits than social media and raise privacy problems given Meta's history. Meanwhile Meta shipped Muse Gadgets (open-source code for DIY Muse devices), the Tamagotchi-like Muse Charm hardware landed in gadget roundups, and an Inc. columnist's claim that Muse knew his private messages (which Meta disputes) helped push Apple's Mac permission changes below.

### [OpenAI's safety turmoil deepens: a resignation, firings, an IPO delay, and an FTC probe](https://www.theatlantic.com/technology/2026/10/openai-safety-team-resignation/688881/)
*(4 newsletters)*

David Robinson, who oversaw safety reports for 12 frontier launches and drafted OpenAI's Preparedness Framework, quit after 3.5 years with an Atlantic essay calling the company's culture "broken" and arguing labs should be run with nuclear-plant style redundancy. His exit follows OpenAI firing three safety researchers for sharing confidential information with an outside safety group, shelving the GPT-6.1 Astra launch, and Sam Altman saying the [IPO is delayed](https://arstechnica.com/ai/2026/09/openai-delays-ipo-over-ai-safety-concerns/) until the company can make confident safety decisions. Separately, the [FTC confirmed](https://www.cnbc.com/2026/09/30/ftc-ai-probe-openai-anthropic.html) it has been investigating OpenAI, Anthropic, and other labs over consumer product risks since the summer.

### [Decision models arrive in force: Cloudflare Clef, Perplexity, Amazon, and Kev](https://blog.cloudflare.com/clef-decision-models/)
*(4 newsletters)*

Cloudflare released Clef and Clef-flash, open-source (Apache 2.0) "System 1" models that pick from a fixed set of answers and return probabilities, so agents can route tickets, classify content, or decide when to defer to a human. They are Jev-API compatible, run on Workers AI or locally, and start at $0.24 per million input tokens ($0.09 for flash). The same day brought Perplexity's cheaper Decisions API and [pplx-decider-v1-27b](https://huggingface.co/perplexity-ai/pplx-decider-v1-27b), Amazon's small [Strands Decider 2B](https://strandsagents.com/blog/introducing-strands-decider/), and [Kev](https://jaredpalmer.com/blog/introducing-kev), a family of four open decision models from 0.8B to 27B.

### [Tavus' Griffin "Human Interaction Model" fooled 48% of testers](https://www.tavus.io/griffin)

### [Claude-shaped science: a physicist's weeks of code reproduced in 20 minutes](https://www.anthropic.com/research/claude-shaped-science)
*(2 newsletters)*

Harvard physicist Matthew Schwartz used Claude to build BootLoops, an open-source toolkit for quantitative calculations across fields from ecology to population genetics. Claude reproduced one paper's results in about 20 minutes versus weeks of original coding, and BootLoops computed 30 physics integrals, 15 of them reportedly never computed before, though Schwartz stresses technically correct output still needed experts to make it scientifically meaningful.

### [Anthropic ships "mods" for Claude Code](https://claude.dev/blog/getting-started-with-claude-code-mods/)
*(2 newsletters)*

Mods are small TypeScript add-ons that change how Claude Code looks and behaves, can replace built-ins like `/diff`, and load instantly; you can write them yourself or ask Claude to build one. They are not sandboxed, so stick to trusted sources. Early examples include a memory "weather forecast," a guard that pauses risky delete commands, and a spinner that turns agent work into pixel-art cartoons.
