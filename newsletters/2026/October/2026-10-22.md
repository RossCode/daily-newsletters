## Top Stories

### [Anthropic launches Claude Duet, a proactive personal agent](https://claude.com/resources/articles/claude-duet)
*(3 newsletters)*

Claude Duet is a standalone Opus 5.5 agent that runs on its own cloud computer, works while your devices are off, and handles things like morning briefs, calendar tracking, and meeting booking. It carries over Claude memory, skills, and connectors, can make purchases through Stripe's Link and Shopify's Shop Pay, and requires sign-off for any deletion, payment, signature, or outgoing message; some actions like trading stocks are blocked outright. TLDR notes it is pitched at work rather than personal errands, unlike OpenAI's dots and Meta's Muse, and the research preview is rolling out via waitlist to US Pro and Max subscribers.

### [AI-found PHP flaws headline a very bad security day](https://techcrunch.com/2026/10/21/the-internet-is-having-a-very-bad-cybersecurity-day/)
*(2 newsletters)*

PHP, which runs roughly 70% of websites, [patched two critical unauthenticated remote code execution bugs](https://thephp.foundation/blog/2026/10/21/todays-php-security-release-and-how-were-strengthening-php-security/) that were found using OpenAI's GPT-5.6 Sol (and separately by Wiz with Sol and Gemini 4 Argon); the NSA told anyone unable to patch to take systems offline, and several European governments pulled sites. [OpenAI says](https://openai.com/index/coordinated-disclosure-of-critical-vulnerabilities/) these are two of "several significant vulnerabilities" it is still working through. The same day brought four high-severity Node.js fixes, a compromised LiteLLM release, and a key compromise at Indian certificate authority eMudhra.

### Voice agent models: Eleven Realtime and Voxtral 3
*(5 newsletters)*

ElevenLabs shipped [Eleven Realtime](https://elevenlabs.io/realtime), speech-to-speech models that can replace OpenAI's Realtime API by swapping only the endpoint and model name, with a cheaper Mini tier and a reasoning Max tier. Mistral released [Voxtral 3](https://mistral.ai/news/voxtral-3/), covering transcription in 50+ languages, expressive TTS in 35+ languages, and a LiveKit-based agent SDK that lets you swap the LLM or voice and self-host the full stack. This was the most widely covered launch of the day.

### [PyTorch gets native backends beyond Nvidia: TorchTPU and TorchNeuron](https://pytorch.org/blog/introducing-torchtpu/)
*(3 newsletters)*

Google and Meta released TorchTPU, an open-source PyTorch backend for TPUs with eager execution and torch.compile support. AWS put [TorchNeuron](https://pytorch.org/blog/introducing-torchneuron-native-pytorch-backend-for-aws-trainium/) into public beta for Trainium, porting PyTorch apps with a config change, and says it will contribute upstream to make PyTorch less CUDA-centric. Together they are the clearest push yet to loosen Nvidia's software lock-in.

### [Meta: Muse passes 10M users as Meta adds a nonvoting share class](https://techcrunch.com/2026/10/21/meta-says-muse-has-over-10m-users-with-shopping-a-top-activity/)
*(4 newsletters)*

Meta's Muse agent hit 10.2M US downloads in 40 days, with over a quarter of engaged users shopping through it at an average purchase above $200; Walmart is already a partner. Meta is also [issuing a nonvoting share class](https://www.reuters.com/business/meta-issue-new-class-shares-it-tightens-ai-spending-forecast-2026-10-21/) to help fund an AI buildout of up to $145B, which TLDR reports came after Zuckerberg pressed the board for a way to pay California's proposed billionaire wealth tax without diluting his 60.6% voting control.

### [DeepSeek open-sources DeepInfer, its production inference engine](https://github.com/deepseek-ai/DeepInfer)
*(2 newsletters)*

DeepSeek released the framework it uses to serve V4.1-Flash on Nvidia SM100 GPUs and Huawei Ascend 950 NPUs. It is an offline-inference version, so a KV cache system, prefill/decode disaggregation, and load balancing still need to be built for a full service. DeepSeek says a cluster processes 155 trillion tokens a day and earns $38 per GPU-hour.

### [Ramp builds Laminar, an in-house managed agents platform](https://builders.ramp.com/post/building-laminar)
*(2 newsletters)*

Ramp consolidated its agent products onto a model-agnostic harness built on Postgres, Temporal, and S3, with session state kept separate from disposable sandboxes plus subagents, steering, and shared tracing. The first version took six weeks, with code written entirely by agents and steered by a small senior team. Ramp's caveat: building in-house is cheaper now, but you still need strong engineers on call to run it.

### [tsrs: Cloudflare and VoidZero port TypeScript to Rust](https://blog.cloudflare.com/typescript-rust-port/)
*(2 newsletters)*

Built with the TypeScript team inside the Oxc toolchain, tsrs reports up to 8x faster type checking and about 70% less memory than TypeScript 7.0. Rust lets the compiler run in WebAssembly for browser and embedded environments. An experimental npm release is out, with compatibility gaps remaining.

### [Inside Prometheus, Meta's gigawatt-scale supercluster](https://engineering.fb.com/2026/10/19/data-center-engineering/inside-prometheus-meta-gigawatt-scale-supercluster/)
*(2 newsletters)*

Meta's Ohio cluster is growing toward roughly 1 million GPUs and has already trained the Muse foundation models. Networking, resilience, and power work pushed pre-training goodput above 85% and cut interruptions 99% from peak, with Vera Rubin NVL72 next after GB200/GB300.

### [OpenAI models and Codex come to Google Cloud](https://openai.com/index/openai-models-google-cloud/)
*(2 newsletters)*

OpenAI's frontier models and Codex workflows are landing in Google Cloud's Model Garden, and will also appear inside Google's Antigravity coding app and Gemini Agent. It is a notable crossing of competitive lines between the two labs.
