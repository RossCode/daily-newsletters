## Top Stories

### [OpenAI ships Images 2.6, with GIFs](https://openai.com/index/introducing-images-2-6/)
*(6 newsletters)*

OpenAI rolled out Images 2.6 across ChatGPT, Codex and the API, claiming 50% faster generation, better consistency across edits, and its first image model with motion: it can animate a prompt, photo or sketch into a GIF, with control over speed and individual frames. Developers get two API models, Flare (renders in as little as six seconds) and Sunburst (detailed edits), both supporting SVG output and a new complexity setting. The Rundown's take: fun, and it edges back to No. 1 on Design Arena, but it is an appetizer while everyone waits on the next frontier model.

### [Investors push back on Anthropic's $1.5T IPO price](https://www.wsj.com/finance/major-investors-are-skeptical-anthropic-ipo-can-achieve-1-5-trillion-valuation-ca965d8b)
*(4 newsletters)*

Major investors in Anthropic's IPO, expected the week before Thanksgiving, say the $1.5 trillion target will likely come down, with the raise now pegged near $80 billion (down from up to $100 billion) and a valuation closer to $1 trillion. The fundamentals behind the jitters: Ramp data shows the top 1% of AI spenders cut per-employee AI spend from July to September and Anthropic's quarterly revenue add slowed from $6.8B in Q2 to [$5.4B in Q3](https://www.saastr.com/the-top-1-of-ai-spenders-stalled-in-q3-so-did-anthropics-dollar-growth/), while [Tom Tunguz estimates](https://tomtunguz.com/the-financial-engineering-essential-for-ai-in-2027/) its average GPU cost rose 82% in two quarters and a $5B short-term compute bill flipped Q3 back to a loss. His prediction: labs will push enterprises into multiyear minimum commitments to match their GPU leases.

### [The election-day revolt against data centers](https://stratechery.com/2026/ai-on-the-ballot/)
*(3 newsletters)*

Nearly every local ballot measure opposing data centers won or is winning (North Dakota the exception), and the WSJ frames the midterms as a [voter revolt](https://www.wsj.com/tech/ai/the-election-day-revolt-that-threatens-americas-ai-boom-03a53b52) that could slow the compute build-out labs are already struggling to secure. Ben Thompson argues the constraint on AI is becoming political, meaning AI capacity stays scarce longer than expected. On the federal side, Rep. Yassamin Ansari called for a pause on advanced AI and a superintelligence ban as "day 1" priorities for the new House majority.

### [OpenAI's agents find and patch Linux kernel bugs at scale](https://openai.com/index/introducing-gpt-6-cyber/)
*(3 newsletters)*

OpenAI's autonomous security pipeline reproduced 1,724 Linux kernel vulnerabilities and generated working exploits for 948 distinct local privilege escalation flaws, plus candidate patches, for about $1.2M in API cost. One lesson: validation has to check *how* an exploit succeeds, since some agents got root through a different bug than the one assigned. OpenAI also released GPT-6 Cyber, a model built for finding and exploiting flaws that beats GPT-6 Astra on most cyber tasks and found 81 serious new Firefox bugs in testing.

### [*sshole: password-free SSH logins on musl systems](https://arstechnica.com/security/2026/11/vulnerability-allows-attackers-to-log-into-some-linux-devices-sans-password/)
*(3 newsletters)*

A bug in OpenSSH on musl-based systems without PAM lets attackers log in without the password, because musl's `crypt()` failure marker can match an account's stored password field. Alpine Linux 3.16 through 3.24 is affected; the [Alpine advisory](https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/) says to update openssh and restart sshd or disable password logins now. Worth checking any Alpine-based containers or appliances that expose SSH.

### [Inside GitHub's new Git storage architecture](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/)
*(2 newsletters)*

GitHub's "Rubicon" design moves immutable Git objects into Azure Blob Storage and puts ref updates in a dedicated replicated log, so compute, storage and maintenance scale independently. Internal tests hit 5,000 concurrent agents and 7,200 pushes per second against a single repo, explicitly designed for agentic development at scale.

### [Apple cuts engineers' daily AI budgets](https://techcrunch.com/2026/11/04/apple-is-reportedly-cutting-budgets-for-its-internal-ai-usage/)
*(2 newsletters)*

Apple lowered some engineers' daily AI spend caps from $300 to $200, with some teams possibly dropping to $100 and non-engineering groups from $100 to $25; anything more needs senior leadership sign-off. Employees say few used the full $300, but The Code reads it as the end of "tokenmaxxing" and the start of rationing, which fits the Ramp spend-stall data above.

### [Cognition releases SWE-2 Flash](https://cognition.com/blog/swe-2-flash)
*(2 newsletters)*

Cognition's new lightweight coding model targets routine agent work like code review, doc updates and small features, running 3x faster than SWE-2 at one-fifth the cost while slightly beating it on FrontierCode 2.0. Weights are private, so it only runs inside Devin.

### [Ripple-65B: frontier-level open weights for $32M](https://www.ricursive.com/ripple)
*(2 newsletters)*

Ricursive's dense 65B open-weight model claims state of the art on TerminalBench 2.1 (80.52), beating open models up to 15x larger, with a 1M-token context and a total training cost of $32M, about a tenth of the prior open SOTA for agentic coding. It is available on Hugging Face, Together, GMI Cloud and OpenRouter.

### [Claude adds a Personal Finance tool](https://techcrunch.com/2026/11/05/claude-can-now-analyze-your-spending-with-its-new-personal-finance-tool/)
*(2 newsletters)*

Claude can now connect to bank and credit card accounts via Plaid and answer questions like "where did my money go this month?" Access is read-only, and it arrives about six months after ChatGPT's comparable feature.

### [Keeping your judgment when agents do the work](https://archive.codenewsletter.ai/2117512471930167377)
*(2 newsletters)*

Addy Osmani (Claude Code at Anthropic) warns that better agents erode critical thinking, sliding from offloading to deferral to "cognitive surrender," leaving repos full of passing tests nobody understands. His fixes: draft your own hypothesis first, define verification before prompting, inspect raw outputs before the summary, and make the agent list the decisions and trade-offs it made, which TLDR Founders also highlighted the same day.

### [Notion becomes infrastructure for agents](https://x.com/NotionHQ/status/2118059335930744999)
*(2 newsletters)*

Notion's CEO says agents now create roughly half of Notion's pages and MCP traffic from connected agents is up about 60x this year, and he is steering the product toward keeping company context current for other vendors' agents. In the same vein, Notion now lets ChatGPT, Claude, Muse and other agents save memories and share skills through one workspace.
